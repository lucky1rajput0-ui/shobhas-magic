# Shobha’s Magic

Premium Indian sweets and festive gifting from Kolkata.

**30 Years of Tradition. Made for the World.**  
Rooted in Bihar & Uttar Pradesh. Crafted in Kolkata. Made for everyone.

Live shop: browse traditional sweets, festive / wedding / corporate gift boxes, and order on WhatsApp — no account required.

## Shop

- Traditional sweets: Thekua, Khajur, Tilkut, Gujiya, Peda, Anarsa
- Festive, wedding and corporate gift boxes
- Coming soon: Makhana, Sattu, Namkeen, spices and pantry essentials

Orders confirm on WhatsApp: **+91 93116 73027**

## Run locally

```bash
npm install
npm run dev
```

Then open the app in your browser.

```bash
npm run build
```

## Stack

React, TanStack Start, Tailwind CSS. Cart and wishlist live in the browser. Checkout generates a WhatsApp order with product, weight, quantity, total and delivery details.
